5. 목표 속도 기반 젯봇 제어

실제 동작 영상

교통표지판 실시간 분류부터 인식 결과를 활용한 젯봇 주행 제어까지 실제 동작을 확인했습니다.

01

5종 교통표지판 실시간 분류

CSI 카메라 영상에서 적색·청색 신호등, STOP, 좌회전, 우회전 표지판을 실시간으로 인식하고 분류 결과와 신뢰도를 확인했습니다.

02

신호등 인식 기반 출발

적색 신호에서 대기한 뒤 청색 신호를 인식하면 목표 속도를 설정하고 젯봇이 출발하는 동작을 확인했습니다.

03

STOP 인식 기반 감속·정지

주행 중 STOP 표지판을 인식하면 목표 속도를 낮추고, 단계적으로 감속해 정지하는 동작을 확인했습니다.

핵심 코드 및 제어 로직

MobileNetV2 5종 분류 모델 

import torch.nn as nn
                        from torchvision.models import mobilenet_v2
                        
                        class TrafficSignMobileNet(nn.Module):
                        
                            def __init__(self, num_classes=5):
                                super(TrafficSignMobileNet, self).__init__()
                        
                                # ImageNet 사전 학습 모델
                                self.base_model = mobilenet_v2(
                                    pretrained=True
                                )
                        
                                # 기존 1000개 분류층 → 5개 클래스
                                self.base_model.classifier[1] = nn.Linear(
                                    self.base_model.last_channel,
                                    num_classes
                                )
                        
                            def forward(self, x):
                                return self.base_model(x)

목표 속도 기반 젯봇 가감속 제어 

# 속도 제어 설정
                        current_speed = 0.0
                        target_speed = 0.0
                        speed_step = 0.05
                        
                        # 표지판 인식 결과에 따른 목표 속도 설정
                        if detected_label == "green_light":
                            target_speed = 0.4
                        
                        elif detected_label in ["red_light", "stop_sign"]:
                            target_speed = 0.0
                        
                        # 목표 속도까지 단계적으로 가감속
                        if abs(current_speed - target_speed) > 0.01:
                            if current_speed < target_speed:
                                current_speed += speed_step
                            else:
                                current_speed -= speed_step
                        
                            current_speed = max(
                                0.0,
                                min(1.0, current_speed)
                            )
                        
                        # 모터 속도 적용
                        robot.set_motors(current_speed, current_speed)
