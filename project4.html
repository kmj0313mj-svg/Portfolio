프로젝트 배경

범죄 예방·산업 안전·캠퍼스 보안 등에서 지능형 CCTV 수요가 증가하고 있으나, 기존 방식은 대부분 모션 감지(Motion Detection)나 배경 차분에 의존해 밝기 변화·그림자·작은 물체 흔들림에도 반응하여 오탐(False Alarm)이 잦습니다.

또한 person에 한정한 침입 판단과 사용자 지정 ROI 기준의 정밀 감시, 그리고 침입 시점 중심의 자동 영상 기록이 부족해 실질 보안·사후 분석에 한계가 있었습니다.

본 연구에서는 최신 경량 모델 YOLOv11n을 적용하여 라즈베리파이 5에서 사람 탐지·ROI 침입 판단·약 3초(45프레임) 이벤트 저장·GUI가 연동된 실시간 침입 감지 CCTV를 설계·구현하고, 실험으로 성능을 검증하였습니다.

사용 기술

Raspberry Pi 5 PiCamera2 Ultralytics YOLOv11n OpenCV-Python Python 3.11 MJPG / AVI

해결 목표

PiCamera2 실시간 입력 위에서 YOLOv11n으로 person만 탐지하고, ROI 교차로 침입을 판정하며, 3프레임 디바운싱으로 안정화한 뒤 침입 확정 시에만 약 3초 분량 이벤트 AVI를 저장하고 GUI로 시각화하는 엣지 CCTV 구축

핵심 구현

01

카메라 입력·YOLOv11n 추론

PiCamera2로 640×480 RGB 스트림을 획득하고, 실시간성 확보를 위해 2프레임마다 1회만 YOLOv11n 추론을 수행합니다.

  • 모델: yolo11n.pt, Ultralytics 패키지
  • 추론 파라미터: imgsz=448, conf=0.45
  • 중간 프레임은 직전 추론 결과를 활용해 ROI 판정·화면 갱신
  • person 클래스만 필터링하여 비인간 객체 반응 억제
02

ROI 교차·디바운싱

사용자 정의 ROI (x1, y1, x2, y2)와 탐지 bbox의 Overlap으로 침입 후보를 판단합니다.

  • 최근 3프레임 결과를 큐로 유지하고, 연속 3프레임 모두 침입일 때만 stable_intrusion 확정
  • 일시적 노이즈·조명 변화로 인한 단발 오탐 억제
  • 상태: Idle → Detection → Normal(ROI 미교차) / Intrusion(ROI 교차) → Recording
03

이벤트 저장·GUI

stable_intrusion이며 녹화 중이 아닐 때만 VideoWriter로 새 AVI를 생성합니다.

  • MJPG 코덱, 약 45프레임(약 3초) 저장 후 자동 종료
  • 녹화 중 화면 상단에 “RECORDING” 오버레이 표시
  • 실시간 영상·탐지 박스·ROI·이벤트 상태를 GUI에 통합 표시

핵심 코드

Algorithm 1에 제시된 유사코드 흐름을 바탕으로, 디바운싱·이벤트 녹화·2프레임 스킵 추론의 핵심을 정리했습니다.

초기화·디바운싱·2프레임 추론 (요약)

# Load YOLOv11n — yolo11n.pt, person 탐지
# ROI = (x1, y1, x2, y2)  # 사용자 지정
# PiCamera2: 640×480 RGB
# intrusion_history: 최근 3프레임 [False, False, False]

frame_count <- 0
while camera_active:
    frame <- CaptureFrame()
    frame_count <- frame_count + 1
    if frame_count % 2 == 0:
        results <- YOLOv11n(frame, imgsz=448, conf=0.45)
    intrusion <- FALSE
    for det in results:
        if det.class == "person" and Overlap(det.bbox, ROI):
            intrusion <- TRUE
    Update intrusion_history  # oldest 제거 후 append
    stable_intrusion <- all(intrusion_history)  # 3프레임 연속 True
    # ... stable_intrusion 시 Recording 시작, 45프레임 후 종료

검증 결과

Raspberry Pi 5에서 실시간 FPS, 침입 감지 정확도(정탐/오탐/미탐), 전체 녹화 대비 이벤트 녹화 저장량, 기존 연구와의 비교를 동일한 지표로 정리했습니다.

실시간 처리 FPS

평균 225.22 FPS

  • • 5회 반복, 각 200프레임 처리 시간 측정 후 평균 FPS 산출
  • • 최소 4.17 / 최대 542.47 (측정 구간·루프 특성에 따른 분산)
  • • 실시간 CCTV 응용에 요구되는 처리 속도를 충족하는 것으로 정리됨

침입 감지 정확도

P 88.9% R 88.9%

  • • 10회 실험: 정탐(TP) 8, 오탐(FP) 1, 미탐(FN) 1
  • • 정상 침입(ROI 중앙 통과) 5회: 전부 정확 탐지
  • • ROI 경계 스침 5회: bbox·경계 부분 겹침으로 FP/FN 각 1회 — 디바운싱이 단발 노이즈 억제에 기여

저장 효율

약 86.8% 절감

  • • 1분 전체 저장(A): 약 42.3 MB
  • • 침입 시점만 3초×3회 이벤트 저장(B): 약 5.6 MB
  • • 3회 침입 이벤트 모두 정상 저장 — 성공률 100%

기존 연구 비교

ROI·이벤트 저장

  • • Nguyen & Ta (Pi 3B, YOLO): 약 2 FPS 대비 본 시스템은 약 225 FPS 수준으로 보고
  • • 조준호 (YOLOv5+CNN 얼굴): 약 25–30 FPS 대비 높은 처리량·ROI 침입·이벤트 저장 기능 차별화
  • • 본 연구: ROI 침입 판단·이벤트 기반 저장·저장 공간 절감 실험 입증
