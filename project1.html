운전자 인증 및 졸음 감지 시스템

기간 2025.09 - 2025.12
팀 구성 5명

프로젝트 소개

등록된 운전자만 차량의 시동을 걸 수 있고, 주행 중 운전자의 졸음 상태를 실시간으로 감지하는 운전자 모니터링 시스템을 구현했습니다. Jetson Nano를 기반으로 얼굴 등록 및 인증, 시동 제어, 졸음 감지, 하드웨어 경고가 하나의 흐름으로 동작하도록 구성했습니다.

핵심 구현

01

InsightFace 기반 얼굴 등록 및 인증

등록 단계에서 저장한 얼굴 특징과 현재 입력된 얼굴 특징을 비교해 동일 사용자인지 판단했습니다.

  • 카메라로 입력된 얼굴에서 InsightFace 특징 벡터 추출
  • 등록 시 추출한 얼굴 특징 정보를 저장해 인증 기준 데이터로 활용
  • 현재 운전자 얼굴 특징과 등록 얼굴 특징 간 Cosine Similarity 계산
  • 유사도 기준에 따라 미등록 사용자는 LOCKED, 등록 사용자는 READY 상태로 판별

02

인증 결과와 시동 상태 연동

인증 성공 후 READY 상태에서 시동 버튼을 입력하면 시동 상태로 전환되고, 이후 졸음 모니터링이 시작되도록 구성했습니다.

  • 인증 성공 후 READY 상태에서 시동 버튼 입력 가능
  • 시동 버튼 입력 시 Engine ON 상태로 전환
  • 시동 이후 MediaPipe 기반 졸음 모니터링이 시작되도록 동작 흐름 연동

03

MediaPipe EAR 기반 졸음 감지

EAR은 눈이 감길수록 값이 작아지는 지표로, 이를 이용해 눈 감김 상태와 지속 시간을 판단했습니다.

  • MediaPipe FaceMesh로 눈 주변 랜드마크 추출
  • 랜드마크 좌표를 이용해 EAR (Eye Aspect Ratio) 계산
  • 눈 감김 시간을 누적해 짧은 깜빡임과 지속적인 눈 감김을 구분
  • 눈 감김이 5초 이상 지속되면 졸음 상태로 판단
  • 졸음 판정 결과가 LED·부저 경고로 이어지도록 시스템에 연동

핵심 코드

얼굴 인증과 졸음 감지에 사용한 핵심 연산 로직입니다.

코사인 유사도 기반 얼굴 인증

import numpy as np AUTH_THRESHOLD = 0.6 def cosine_similarity(vec1, vec2): dot_product = np.dot(vec1, vec2) norm1 = np.linalg.norm(vec1) norm2 = np.linalg.norm(vec2) return dot_product / (norm1 * norm2) # 입력 얼굴과 등록 얼굴의 특징 벡터 유사도 계산 similarity = cosine_similarity( input_embedding, registered_embedding ) # 기준값 이상이면 등록 사용자로 판단 is_registered = similarity >= AUTH_THRESHOLD

EAR 계산 및 졸음 판단 기준

import numpy as np def calculate_ear(eye_landmarks): p1, p2, p3, p4, p5, p6 = eye_landmarks vertical_1 = np.linalg.norm( np.array(p2) - np.array(p6) ) vertical_2 = np.linalg.norm( np.array(p3) - np.array(p5) ) horizontal = np.linalg.norm( np.array(p1) - np.array(p4) ) ear = (vertical_1 + vertical_2) / (2.0 * horizontal) return ear # 졸음 판단에 사용할 EAR 기준값과 지속시간 EAR_THRESHOLD = 0.25 DROWSY_TIME_LIMIT = 5.0

배운 점

이번 프로젝트를 통해 개별 기능을 구현하는 것뿐 아니라, 각 기능 사이의 조건과 동작 순서를 함께 설계하는 것이 중요하다는 점을 배웠습니다. 얼굴 인증 결과가 시동 제어로 이어지고, 시동 이후 졸음 감지가 동작하도록 연결하면서 여러 기능을 하나의 시스템으로 통합하는 과정을 경험했습니다.
