핵심 구현

01. InsightFace 기반 얼굴 등록 및 인증

GPIO 등록 버튼 입력 시 카메라로 얼굴을 촬영하고, InsightFace로 얼굴 특징 벡터를 추출해 등록 정보를 저장했습니다. 인증 단계에서는 현재 운전자의 특징 벡터와 등록된 정보를 코사인 유사도로 비교해 등록 여부를 판단하고, 인증 결과에 따라 LOCKED/READY 상태가 전환되도록 구현했습니다.

02. MediaPipe 기반 실시간 졸음 감지

시동 후 MediaPipe FaceMesh로 눈 주변 랜드마크를 추출하고, 랜드마크 좌표를 이용해 EAR을 계산했습니다. EAR이 기준값 이하로 내려간 시간을 누적해 짧은 눈 깜빡임과 지속적인 눈 감김을 구분하고, 5초 이상 지속되면 졸음 상태로 판단하도록 구현했습니다. 판정 결과는 팀에서 구현한 GPIO 경고 로직과 연동되어 LED와 부저가 작동하도록 구성했습니다.

눈 감김 상태 모니터링

EAR이 기준값 이하로 내려간 동안 경과 시간을 누적해 눈 감김 지속시간을 추적했습니다.

졸음 상태 판정 및 경고

눈 감김이 5초 이상 지속되면 Drowsy 상태로 판단하며, 판정 결과가 GPIO 경고 로직으로 전달되어 LED와 부저가 작동하는 것을 확인했습니다.

핵심 코드

얼굴 인증과 졸음 감지에 사용한 핵심 연산 로직입니다.

코사인 유사도 기반 얼굴 인증 

import numpy as np

def cosine_similarity(vec1, vec2):
    dot_product = np.dot(vec1, vec2)

    norm1 = np.linalg.norm(vec1)
    norm2 = np.linalg.norm(vec2)

    return dot_product / (norm1 * norm2)


def verify_user(
    input_embedding,
    registered_embedding,
    threshold=0.6
):
    similarity = cosine_similarity(
        input_embedding,
        registered_embedding
    )

    return similarity >= threshold, similarity

EAR 계산 

import numpy as np

def calculate_ear(eye_landmarks):
    p1, p2, p3, p4, p5, p6 = eye_landmarks

    vertical_1 = np.linalg.norm(np.array(p2) - np.array(p6))
    vertical_2 = np.linalg.norm(np.array(p3) - np.array(p5))
    horizontal = np.linalg.norm(np.array(p1) - np.array(p4))

    ear = (vertical_1 + vertical_2) / (2.0 * horizontal)

    return ear
